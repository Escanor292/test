---

Use this template:

```markdown
## Summary

<diagram, diff-sketch, or tree>

## Evidence

- **Before:** <screenshot/output/failing test>
  **After:** <screenshot/output/passing test>

## Merge Danger

**Door:** <one-way or two-way>
**Blast Radius:** <one-word>
```

Use the smallest visual that makes the change clear (pseudocode, call tree, Mermaid, diff). Keep prose brief. Use domain language from `GLOSSARY.md`.
